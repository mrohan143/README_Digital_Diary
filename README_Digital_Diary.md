# Digital Diary System in C++

## Project Overview
The Digital Diary System is a simple C++ project that allows users to save personal diary entries digitally. Users can add notes, view saved entries, and search diary records by date.

This project is based on Object-Oriented Programming (OOP) concepts and File Handling.

---

## Features
- Add Diary Entries
- View All Saved Entries
- Search Entry by Date
- Store Data in Text File
- Menu Driven Interface

---

## Concepts Used
- Classes & Objects
- Constructor
- Encapsulation
- Functions
- Loops
- Conditions
- File Handling

---

## Technologies Used
- C++
- File Handling
- OOP Concepts

---

## Files Included
- `digital_diary_system.cpp`
- `diary.txt` (Automatically created after saving entries)

## How to Run the Project

### Step 1: Compile the Program
```bash
g++ digital_diary_system.cpp -o diary
```

### Step 2: Run the Program
```bash
./diary
```
